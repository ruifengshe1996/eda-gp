# DREAMPlace 目标函数各项的设计逻辑与运行期演化

依据 `dreamplace-src/dreamplace/PlaceObj.py`、`NonLinearPlace.py` 与
`ops/{weighted_average_wirelength, electric_potential, density_overflow}/`
源码整理。`docs/ALGORITHM_FLOW.md` 讲的是**流程**（谁在什么时候被调用），
本文讲的是**目标函数本身**：每一项是什么、为什么这样设计、以及它在一次
布局过程中如何随迭代演化。本项目历次实验测出的数值用 **[实测]** 标注，
引用来源在括号里。术语见 `docs/NOTATION.md`。

## 0. 总式

DREAMPlace 求解的是一个**无约束最小化**（`PlaceObj.obj_fn`）：

```
f(x) = Σ_e  w_e · WA_γ(e; x)            ← 线长项（可微代理）
     + ρ · λ · Φ(x) · [1 + c·Φ(x)]      ← 密度项（静电势能，可选二次项）
```

- `x`：全部单元（可动 + 固定 + filler）的 (x, y) 坐标；
- `w_e`：网线权重，ISPD2005 上全为 1（仅时序/可布线性优化会改它）；
- `γ`：线长模型的平滑参数（§1）；
- `λ`：密度权重（§3）；`ρ` = `density_factor`，初值 1，平台期可翻倍；
- `Φ`：静电势能（§2）；`c` = `quad_penalty_coeff`，仅在 `quad_penalty`
  打开后生效（§3.4）。

**它没有任何硬约束**——密度合法性不是约束，而是一个权重不断增长的罚项。
所有"约束满足"都来自 λ 的爬升把 Φ 的梯度逐步放大到能与线长梯度抗衡。
优化器看到的不是 ∇f 本身，而是经过**预条件器**（§4）逐单元缩放后的
梯度。

术语说明：本文标题沿用了"奖励项"的提法，但从优化方向看它们都是**惩罚
项**（越小越好）；本文一律称"项"。

## 1. 线长项：加权平均（WA）模型

### 1.1 定义

对每条网线 e、每个坐标轴（以 x 为例），

```
WA_γ(e) = Σ_{i∈e} x_i·exp(x_i/γ) / Σ_{i∈e} exp(x_i/γ)
        − Σ_{i∈e} x_i·exp(−x_i/γ) / Σ_{i∈e} exp(−x_i/γ)
```

（`weighted_average_wirelength_cuda_merged_kernel.cu`；实现里先减去
x_max / x_min 防溢出）。度数 > `ignore_net_degree`(100) 的巨网被
`net_mask` 屏蔽，不计线长也不产生梯度。

### 1.2 设计逻辑

真实指标 HPWL = Σ_e (max x − min x) 不可微、且梯度只落在每条网线的两个
极端引脚上——中间引脚**完全没有力**，优化器无法同时移动一整簇单元。
WA 是 HPWL 的光滑上界代理，其两个极限说明了 γ 的含义：

| γ | WA 趋于 | 梯度 |
|---|---|---|
| → 0 | max − min（HPWL） | 集中在极端引脚，O(1) |
| → ∞ | mean − mean = **0** | **趋于 0**（所有引脚均分、彼此抵消） |

所以 **γ 大 = 平滑且弱的线长力**，γ 小 = 锐利且强的线长力。这一点在
本项目多处结论里承重（§5、§6）。

### 1.3 梯度

对引脚 i（合并核里 `grads[flat_netpin[j]] = (a_x + b_x·x)·exp_x −
(a_nx + b_nx·x)·exp_nx`）：靠近 x_max 的引脚受正向拉力、靠近 x_min 的
受反向拉力，幅度由 softmax 权重决定。梯度再经 `pin2node` 汇总到单元，
乘以 `w_e`（`integrateNetWeights`）。

### 1.4 运行期演化：γ 的调度

`update_gamma`（每迭代一次）：

```
base_γ = gamma(4.0) × (bin_w + bin_h)
γ(t)   = base_γ × 10^((ov(t) − 0.1)·20/9 − 1)
```

ov=1.0 → 系数 10（最平滑）；ov=0.6 → 1.29；ov=0.1 → 0.1。构造时
γ = 10·base_γ。这是一个**由当前平均 overflow 瞬时决定**的同伦：起点
平滑（避免陷入引脚级局部极小、让整簇一起动），随着密度合法化推进逐步
锐化到接近 HPWL。

**[实测]** 这个瞬时映射对初始化有一个正反馈（`OVERFLOW_ANALYSIS` §4）：
铺开起点 overflow 低 → 第 1 迭代就拿到锐 11 倍的模型（obsspread γ=151
vs center 1666）→ 收拢更强 → 铺开被更快抹除。

本项目加的旋钮：`gamma_warmup_iters` / `gamma_monotone_flag`（实验 3，
已证伪）；`gamma_local_*`（实验 13，逐网线 γ，已证伪——见 §6.3）。

## 2. 密度项：ePlace 静电势能

### 2.1 定义

（`electric_potential.py`，`ElectricPotentialFunction`）

1. **栅格化**：可动单元 + filler 按面积摊到 bin 上得到电荷密度 ρ(b)。
   小单元的尺寸会被 clamp 到不小于 bin 尺寸并按 `ratio` 保面积，避免
   亚 bin 单元产生零梯度；固定单元预先摊进 `initial_density_map`；
2. **求电势**：泊松方程 ∇²φ = −ρ 用二维 DCT 求解：
   `φ̂(u,v) = ρ̂(u,v) / (wu² + wv²)`（直流分量置零）；
3. **能量**：`Φ = Σ_b φ(b)·ρ(b)`；
4. **场**：`E_x = IDXST·IDCT(ρ̂·wu/(wu²+wv²))`，E_y 同理；
5. **对单元的力**（backward）：`∂Φ/∂x_i = −面积_i × E_x(单元所覆盖 bin)`。

### 2.2 设计逻辑

把单元当作电荷、密度当作电荷分布，势能最小 ⇔ 电荷均匀 ⇔ 密度均匀。
相比早期的 bell-shape 势能，静电模型的力是**全局光滑**的（由泊松方程
的格林函数决定），远处的拥塞也会对本地单元产生推力，不会出现"局部平坦、
无梯度"的死区。

**filler 的角色**：filler 的总面积 = 可布面积 × target_density −
可动面积（`PlaceDB.initialize_filler`），尺寸 = 平均可动单元宽 × 行高。
它们进入密度项、不进入线长项。加入 filler 之后，总电荷恰好填满目标
密度下的版图——只有当真实单元与 filler 共同均匀铺开时电场才为零。
换言之，**filler 把"密度 ≤ 目标"这个不等式约束改写成了"密度 = 目标"
的等式**，这是静电模型能用一个势能表达合法性的前提。

**[实测]** 由于 filler 无条件均匀撒满版图（`ALGORITHM_FLOW` §1），对
铺开初始化它们会压在真实单元准备好的位置上；实验 10 的 N2 试图按
逆密度播种，结果整体变差——均匀 filler 的"虚假密度"是解团催化剂，
不是缺陷。

### 2.3 overflow：密度项的观测量（不是目标项）

`density_overflow` 算子单独计算 `overflow = Σ_b max(0, ρ(b) −
target·bin_area) / 可动总面积` 与 `max_density`。它**不进入目标函数**，
只用于：γ 调度（§1.4）、停机判据（§5）、发散检测、最优快照、以及本项目
所有 overflow 侧分析。**[实测]** 最终 overflow 被停机判据钳在 0.07 附近，
跨变体无差别（`OVERFLOW_ANALYSIS` §1）；bin 级峰值 `max_density` 能
暴露标量 overflow 看不见的局部违例（shrink001 在 bigblue4 留下 5.38）。

## 3. 密度权重 λ：目标函数里唯一"会动"的系数

### 3.1 初值：梯度比归一化

`initialize_density_weight`，在加噪后的初始状态、第一次下降步之前调用：

```
λ₀ = density_weight(8e-5) × ‖∇WL(x₀)‖₁ / ‖∇Φ(x₀)‖₁
```

设计意图：让 t=0 的密度合力恰好是线长合力的 1/12500，**与设计规模、
单位制、初始状态无关**——这是 ePlace 让同一组参数跨设计工作的关键
归一化。

**[实测]** 副作用（`OVERFLOW_ANALYSIS` §5，实验 12 干预验证）：这也
意味着初始几何对密度侧的**全部**影响被压缩成 ‖∇Φ(x₀)‖₁ 这一个数。
铺开态密度平坦 → ‖∇Φ‖ 小 → λ₀ 大（obsspread 比 center 大 502~1368 倍）。
把 λ₀ 直接设成 obsspread 的值而几何保持 center，就复现了 obsspread 的
全部迭代节省（−26.9% vs −30.1%）。旋钮：`initial_density_weight_absolute`
（实验 10 引入）。

### 3.2 更新律（无围栏区：HPWL 模式）

`update_density_weight_op_hpwl`，每迭代一次：

```
ΔHPWL < 0 : μ = 1.05 × max(0.9999^t, 0.98)          ∈ [1.029, 1.050]
ΔHPWL ≥ 0 : μ = 1.05 × clamp(1.05^(−ΔHPWL/350000), 0.95, 1.05)
λ ← λ · μ^s                                            (s = ramp_scale)
```

设计意图（RePlAce）：线长在改善就加快密度力，线长恶化就放慢——一个
符号驱动的乘性控制器。

**[实测]** 实际行为几乎是开环的（实验 11）：`ref_hpwl=350000` 是绝对量而
ISPD2005 的 wHPWL 在 1e8~1e9，第二分支几乎总撞下界；adaptec1 的 611 次
更新里只有 13 次下降。λ 在所有设计上都跨越恒定的 **9.8~10.5 个十进制位**
（从 ~1e-11 到 ~7e-2），终点 λ_F 与初始化无关（7/8 设计极差 ≤11%），
于是 `迭代数 ≈ 位数 × ln10 / ln μ`。**迭代数是这个更新律的超参数，
不是设计难度的涌现属性。** 旋钮：`density_weight_ramp_scale`（实验 11）；
s=1.43 用 +0.53% wHPWL 换 −25% 迭代，是目前最便宜的速度杠杆。

围栏区设计走另一条 `overflow` 模式（elfPlace 的次梯度更新 +
`update_mask` 逐区冻结），ISPD2005 不触发，本文不展开。

### 3.3 λ 与预条件器的耦合

λ 不只出现在目标函数里，还出现在预条件器分母里（§4）。λ 增大时所有
单元的有效步长同步变小——这是"密度力越强、整体越慢"的来源，也是
后期迭代密集的原因之一。

### 3.4 平台期干预：ρ 翻倍与二次项

`NonLinearPlace` 主循环每迭代检查：若 overflow 在 15 迭代窗口内变化
<0.1% 且距上次干预 >50 迭代且 overflow>0.9，则

- `quad_penalty = True`：密度项变为 `Φ·(1 + c·Φ)`，
  `c = 2000/2 / Φ(x₀)`——用初始势能归一化的二次项，加速高溢出下的
  分离；
- `density_factor` ×2：等效于 λ 瞬间翻倍；
- overflow>0.95 时再追加**熵注入**：全体向质心收缩 ×0.996 + 高斯噪声
  σ = 40~90 版图单位，固定单元复原。

设计意图：对付"堆在中心动不了"的早期死锁。**[实测]** 这些触发条件只在
高溢出平台成立，所以低溢出起点的初始化永远不会收到它们；流程里没有
面向中低溢出阶段的任何长程重排手段（`MECHANISM_ANALYSIS` C3）。

## 4. 预条件器：梯度的逐单元缩放

`PreconditionOp.__call__`：

```
precond_i = max(1, Σ_{e∋i} w_e  +  α·λ·面积_i)      (α ≡ 1，无围栏区)
grad_i   ← grad_i / precond_i
```

设计逻辑：这是 ePlace 的对角 Hessian 近似。线长项对单元 i 的曲率大致
正比于它连接的网线权重和，密度项的曲率正比于 λ × 面积。除以它使得
"引脚多的单元"和"面积大的单元"不会因梯度绝对值大而迈出过大的步——
把优化变成近似的牛顿步。

运行期含义：早期 λ≈0，分母 ≈ 引脚数，线长主导；后期 λ·面积 ≫ 引脚数，
分母由密度项主导，宏单元（面积大）几乎被冻结，标准单元整体减速。
**[关键]** 分母 clamp 在 ≥1，所以孤立小单元（无网线、λ 小）不会被无限
放大。

## 5. 停机、快照与回滚：目标函数之外决定终点的三条规则

- **停机**（`Lgamma_stop_criterion`）：迭代 >100 且（overflow <
  `stop_overflow`(0.07) **且本迭代 HPWL 高于上一迭代**）或
  max_density < target。到达目标溢出后还要等 HPWL 出现一次回升才停——
  "过冲一步"。**[实测]** 这把最终 overflow 钳在 0.066~0.068，密度侧的
  任何改进都只能表现为迭代数。
- **最优快照**：按**最低 overflow**记录 `best_pos`（不是最优 wHPWL）。
- **发散回滚**：仅在 overflow ∈ (0.077, 0.28) 带内，50 迭代窗口 HPWL
  均值高出最优 1.2× 且 overflow 异常时，回退到 `best_pos` 并终止。

## 6. 一次布局中各项的完整时间线 **[实测汇总]**

以 center 初始化的 adaptec1（613 迭代）为例（`experiments/obstacle_field/
logs/center`）：

| 阶段 | 迭代 | λ | γ/base_γ | overflow | 主导项 | 发生了什么 |
|---|---|---|---|---|---|---|
| 0 | 0 | 0 → 7.5e-12 | 10 | 1.00 | — | 加噪、探针步估学习率、λ₀ 归一化 |
| 熔化 | 1~50 | 1e-11 ~ 1e-10 | 10 → 8 | 1.00 → 0.83 | **纯线长** | 单元从中心点向各自网线引力中心扩散，秩序在此隐式求解 |
| 平台 | 50~260 | 1e-10 ~ 1e-7 | ≈8 | **0.82 ± 0.01** | 纯线长 | λ 爬升 3 个数量级，overflow 纹丝不动——**吸引子** |
| 分离 | 260~430 | 1e-7 ~ 1e-4 | 8 → 5 | 0.82 → 0.50 | 线长 ≈ 密度 | 密度力追上线长力，簇被推开，wHPWL 上升 15% |
| 铺开 | 430~600 | 1e-4 ~ 5e-2 | 5 → 0.5 | 0.50 → 0.07 | **密度** | γ 锐化、线长局部微调、预条件分母由 λ 主导 |
| 停机 | 613 | 5.8e-2 | 0.4 | 0.070 | — | HPWL 出现回升，停 |

三个跨初始化的不变量（`OVERFLOW_ANALYSIS`）：

1. **平台期的 overflow 值是设计常数**（吸引子，0.72~0.86）：六种初始化
   从 0.42~1.00 出发，第 100 迭代都落到同一个值。因为此时密度力 <1%，
   overflow 只是线长最优解的读数。
2. **λ_F 是设计常数**：把该设计压到 overflow 0.07 需要的密度权重与
   起点无关。
3. **λ 跨越的位数几乎是常数**（≈10）：所以迭代数 = 位数/斜坡率，两个
   杠杆分别是 λ₀（入口）与 μ（速率）。

### 6.1 各项之间"打架"的地方

- **λ₀ 归一化 vs 初始化**：归一化把任何起点都变成"线长力 : 密度力 =
  12500 : 1"，铺开起点的密度优势被当场抹平（§3.1）。
- **γ 瞬时映射 vs 铺开起点**：低 overflow 换来锐模型，收拢更快（§1.4）。
- **预条件器 vs λ 增长**：λ 越大全体越慢，后期每迭代位移很小，这是
  "长程错误在中低溢出阶段无法修复"的动力学原因之一（§4）。
- **停机判据 vs 密度指标**：终点 overflow 被钳住，密度侧无法在结果里
  留下差异（§5）。
- **两段式宏布局**（`macro_place_flag='auto'`，仅 bigblue3）：stage 0
  结束后 λ 归零、γ 复位，整套演化再跑一遍——bigblue3 的 ~1000 迭代由此
  而来，与 λ 振荡无关（实验 11 勘误 C5）。

### 6.2 哪些杠杆被证明能动、哪些不能

| 想改变的量 | 通过密度项 | 通过线长项 | 通过初始几何 |
|---|---|---|---|
| 迭代数 | ✅ λ₀ / 斜坡率（实验 11/12） | — | ✅ 但只经由 λ₀（实验 12） |
| 早期 overflow（吸引子） | ❌ λ₀ ×800 只动 0.011（E4） | ⚠️ 逐网线 γ 能动 0.07~0.11，但全部推高、且质量 +2~5pp（实验 13，已撤回） | ❌ 100 迭代内被抹除 |
| 最终 wHPWL（去混杂） | ⚠️ 斜坡率 +0.53% @ −25% | ❌ 逐网线 γ +3~5pp | ❌ 残差 ≥ 0，局部例外 |

### 6.3 逐网线 γ 为什么不行（实验 13 的机制教训）

把 γ 做成逐网线量时，§1.2 的极限性质变成了陷阱：**γ 不同的网线拥有
不同的梯度幅度**（锐网线 O(1)，平滑网线趋于 0）。于是"局部化 γ"在
效果上等价于"给网线加了一层随 γ 变化的隐式权重"，与空间结构无关——
保 overflow 均值、保 γ 均值、翻转符号都改变不了这一点。安慰剂臂（保留
γ 的数值多重集合、在网线间随机置换）把损害拆成两部分：**离散度本身
+2.06pp**（隐式加权），**与 overflow 相关的空间指派再加 +1.7~+3.0pp**
（标准映射最差）。也就是说，N4 想利用的那个"局部信息"不只是无用，
而是反向的。教训：**任何让 γ
跨网线异质的方案，都必须同时归一化每条网线的梯度幅度**，否则改的是
权重而不是平滑度。
