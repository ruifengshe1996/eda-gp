# 实验 13：γ 的空间局部化（N4）—— overflow 侧唯一还没被堵死的杠杆

> **本文件在 16 次正式 GPU 运行之前提交（预注册）。** §5 的预测在看到
> 正式数据前写定，§6 结果区在运行后追加，不修改 §5。
> §4.3 记录的两次单设计冒烟运行**发生在写定 §5 之前**，其结论已如实
> 写入 §4.3，并据此选定了本实验的臂——不构成对 §5 的事后修改。

## 1. 背景

`docs/OVERFLOW_ANALYSIS.md` 与实验 12 把密度侧的路堵死了：

- 初始化在密度侧的全部效应等于一个标量 λ₀（实验 12 E1 干预式验证）；
- 最终 overflow 被 `stop_overflow=0.07` 钳住，不含信息；
- 前 ~100 迭代密度力占比 <1%，overflow 是**线长目标的读数**，六种初始化
  都被拉到同一个设计常数**吸引子**（0.72~0.86）；
- **实验 12 的 E4 是决定性的**：把 λ₀ 抬高 502~1368 倍之后，第 100 迭代
  的 overflow 仍是 0.806（center 0.817）——**在密度项加权重打不破吸引子**。

留下的唯一推论：既然早期 overflow 由线长目标决定，能改变它的只有**线长
目标本身**。γ 是线长目标里唯一的形状参数，而它目前是一个由**全局平均
overflow** 驱动的标量。这就是 N4。

## 2. 动机

γ 是全局标量，但 overflow 的空间分布可以差一个数量级：已经铺开的区域和
仍然拥塞的区域拿到同一个线长模型。`MECHANISM_ANALYSIS` 的 N4 提案是让
γ 成为**逐网线**量，由该网线引脚所在 bin 的局部 overflow 决定。

关键是**方向**。`update_gamma` 的映射是 `coef = 10^((ov−0.1)·20/9 − 1)`：

- **高 overflow → 大 γ → 平滑模型 → 弱而弥散的拉力**；
- **低 overflow → 小 γ → 接近 HPWL → 强而集中的拉力**。

（γ→∞ 时 WA 线长趋于 0、梯度趋于 0；γ→0 时退化为 HPWL。所以大 γ = 弱
线长力。这也是机制②的量化来源：obsspread 在第 1 迭代拿到 γ=151，而
center 是 1666，铺开态因此被更强地收拢。）

于是标准映射的空间含义是：**拥塞处放松、空旷处收紧**。这会把外围单元
往回拉，**推高** overflow。而「守住铺开状态」需要的恰恰相反。

`docs/OVERFLOW_ANALYSIS.md` §7A 原文写的是「已铺开区域保持平滑模型、
拥塞区域用锐模型」——那是**相对标准映射反号的**。本实验不预设哪个对，
而是把符号做成一个保均值的开关，直接判。

## 3. 方法

### 3.1 内核改动（默认逐位不变）

`weighted_average_wirelength_cuda_merged_kernel.cu` 里 `inv_gamma` 本来就是
设备指针，只是被解引用成标量。改为 `inv_gamma[ii * gamma_stride]`，
`gamma_stride` 由 `.cpp` 从 `inv_gamma.numel() > 1` 推导：

- 传 1 元素张量 → stride 0 → 每个网线都读 `inv_gamma[0]`，**与原内核逐位
  等价**；
- 传 num_nets 张量 → stride 1 → 逐网线 γ。

绑定签名不变，反向路径不受影响（反向不使用 `inv_gamma`，只是把预计算的
`grad_intermediate` 乘以 `grad_pos`）。

**已验证**：`gamma_local_flag=0` 时 adaptec1 重跑得到 613 迭代 /
wHPWL 7.280647E+07，与同机 center 基线**逐位相同**。

### 3.2 逐网线 overflow

每 `gamma_local_interval` 迭代重算一次（γ 变化很慢，摊薄开销）：

1. 把版图划成 `gamma_local_bins` (64) 的粗网格，把可动单元 + filler 的
   面积散射进去，得到 `ov_bin = clamp(dens/capacity − 1, 0)`；
2. 每条网线取其引脚所在 bin 的 `ov_bin` **最大值**（N4 原文的定义）；
3. **保均值再归一化**：`net_ov *= ov_global / mean(net_ov)`；
4. 可选镜像（§3.3）；
5. `γ_net = base_gamma · 10^((ov_used − 0.1)·20/9 − 1)`，
   其中 `ov_used = (1−α)·ov_global + α·net_ov`。

第 3 步是本实验设计上最要紧的一处。**局部化必须是纯粹的空间再分配**：
若逐网线 overflow 的均值偏离了全局值，同伦调度就会在不知不觉中整体变快
或变慢，"局部化"就与"调度提速/减速"混淆了。保均值把这个混淆消掉。

### 3.3 符号开关（保均值镜像）

`gamma_local_sign = −1` 时把每条网线的 overflow 关于全局值做镜像：
`net_ov ← 2·ov_global − net_ov`。这**精确保持均值**，只把「谁拿到锐模型」
整个翻转。于是两个臂跑的是**完全相同的平均调度**，唯一差别是空间指派——
这是一个干净的符号判据。

### 3.4 运行矩阵

| 臂 | sign | 空间含义 | 运行 |
|---|---|---|---|
| gpos | +1 | 拥塞处放松、空旷处收紧（N4 标准映射） | 8 |
| gneg | −1 | 拥塞处收紧、空旷处放松（`OVERFLOW_ANALYSIS` §7A 的方向） | 8 |

全部 center 初始化，α=1（纯局部），bins=64，interval=10，其余参数与同机
center 基线逐字相同（迭代上限 2000，理由见实验 11 README §3）。
对照复用：center 基线、实验 11 的斜坡前沿。

## 4. 冒烟运行（写定 §5 之前）

### 4.1 第一版（有缺陷，已废弃）

初版把逐 bin overflow 按全局指标归一化并 clamp 到 1。由于一个拥塞 bin 的
值约等于 1/利用率（≈1.4），**几乎每条网线全程饱和在 1**，γ 被钉死在最
平滑档，线长模型永不锐化。adaptec1：904 迭代 / +2.16%。这是实现缺陷，
不是 N4 的结论——修正为 §3.2 第 3 步的保均值归一化。

### 4.2 第二版（保均值，gpos）

adaptec1：**842 迭代（+37%）/ wHPWL 7.397366E+07（+1.60%）**。
按本项目的报告规范折算到斜坡前沿（+37% 迭代处约 −0.13%），
去混杂残差约 **+1.7pp**，明显有害。

### 4.3 冒烟给出的关键信号

| | ov@100 | ov@300 |
|---|---|---|
| center 基线 | 0.819 | 0.795 |
| gpos（α=1） | **0.904** | **0.647** |

**γ 局部化确实移动了 overflow 轨迹**（第 100 迭代 +0.085，第 300 迭代
−0.148），而实验 12 证明 λ₀ 抬高 800 倍只能移动 0.011。**这是本项目第一个
被证实能推动早期 overflow 的杠杆**，与 `OVERFLOW_ANALYSIS` §3 的推论一致
（能改变吸引子的只有线长目标）。

方向符合 §2 的预期：标准映射把外围收紧，overflow 被推**高**。正因为杠杆
是真的、方向是错的，本实验的核心就变成了**符号判据**（§3.3）。

## 5. 预注册预测（写于 16 次正式运行之前）

**G1（内核惰性）——已验证**，见 §3.1，不再作为预测。

**G2（γ 局部化是真实的 overflow 杠杆）**：gpos 与 gneg 在第 100 迭代的
overflow 相对 center 基线的偏移，**在 ≥6/8 设计上绝对值 > 0.03**，且
**两臂方向相反**（gpos 偏高、gneg 偏低）。
- 成立 ⇒ 线长目标侧确实是能推动吸引子的通道，`OVERFLOW_ANALYSIS` §3 的
  推论得到正面证据（此前只有 E4 的反面证据）；
- 不成立（两臂都动不了）⇒ 吸引子对 γ 的空间分布也免疫，那么早期
  overflow 就不是任何可及旋钮的函数，N4/Q5 都应降级。

**G3（镜像有效性 / 健全性检查）**：gneg 的 ov@100 在 ≥7/8 设计上低于
gpos。若不成立，说明镜像实现或保均值归一化有问题，G4 作废。

**G4（质量 —— 主判据，按去混杂口径）**：两臂各自相对**同迭代数 center**
的残差（用实验 11 的斜坡前沿逐设计插值，`experiments/lambda_ramp/analyze.py`
的口径）：
- 预测 gpos 残差 **> +1.0pp**（冒烟给出 +1.7pp）；
- 预测 gneg 残差 **< gpos 残差**；
- **开放问题（本实验的真正回报）**：gneg 的残差是否 **< −0.5pp**，即
  γ 局部化能否成为本项目第一个真正战胜等迭代数 center 的机制。
  按目前所有证据无法预判，故不预测方向。

**G5（拥塞异质性）**：两臂的残差差值 |gpos − gneg| 在拥塞集中的设计
（bigblue2、bigblue3）上大于在均匀设计（adaptec1、bigblue1）上——因为
局部化在 overflow 空间方差大的设计上才有可操作空间。若不成立，说明
逐网线 γ 的作用与拥塞分布无关，机制解释需重写。

## 6. 第一阶段结果（gpos / gneg，16 运行全部 exit=0）

### 6.1 G2 一半成立：杠杆是真的，但两臂同向

| 设计 | ov@100 基线 | gneg | Δ | gpos | Δ |
|---|---|---|---|---|---|
| adaptec1 | 0.819 | 0.893 | +0.074 | 0.892 | +0.073 |
| adaptec2 | 0.855 | 0.935 | +0.080 | 0.962 | +0.107 |
| adaptec3 | 0.855 | 0.964 | +0.109 | 0.985 | +0.130 |
| adaptec4 | 0.771 | 0.910 | +0.139 | 0.934 | +0.163 |
| bigblue1 | 0.829 | 0.902 | +0.073 | 0.896 | +0.068 |
| bigblue2 | 0.725 | 0.841 | +0.116 | 0.828 | +0.103 |
| bigblue3 | 0.853 | 0.932 | +0.079 | 0.983 | +0.129 |
| bigblue4 | 0.830 | 0.915 | +0.085 | 0.921 | +0.091 |
| **均值** | | | **+0.095** | | **+0.108** |

**「杠杆真实」成立**：两臂都在 8/8 设计上把 ov@100 移动了 >0.03，量级是
实验 12 中 λ₀ 抬高 800 倍所能做到的（0.011）的 **8~10 倍**。线长目标侧
确实是能推动吸引子的通道。

**「两臂方向相反」不成立**：两臂都把 overflow 推**高**，且幅度相近。

### 6.2 G3 不成立

gneg 的 ov@100 低于 gpos 的只有 **5/8** 设计（预测 ≥7/8），均值差只有
0.013。**镜像几乎没有产生差别。**

### 6.3 G4：两臂都灾难性变差

去混杂残差（到本设计斜坡前沿）：

| 设计 | gneg 残差 | gpos 残差 |
|---|---|---|
| adaptec1 | +2.86 | +1.98 |
| adaptec2 | **−0.09** | +0.77 |
| adaptec3 | +1.34 | +3.97 |
| adaptec4 | +3.63 | +5.75 |
| bigblue1 | +0.42 | +0.74 |
| bigblue2 | +1.13 | +3.66 |
| bigblue3 | +16.11 | +25.45 |
| bigblue4 | +1.98 | +3.50 |
| **几何平均** | **+3.31** | **+5.48** |

「gneg 残差 < gpos 残差」成立，但**开放问题的答案是否定的**：gneg 远不是
−0.5pp，而是 +3.31pp。

### 6.4 诊断：混杂来自 Jensen 不等式，不是空间指派

「两臂几乎一样」本身就是线索。镜像 `net_ov ← 2·ov_global − net_ov`
**同时保持均值和方差**。如果效应由空间指派方向驱动，两臂应当相反；如果由
γ 的**离散度**驱动，两臂应当相同——观测到的是后者。

原因是 `coef = 10^((ov−0.1)·20/9 − 1) = 10^(2.222·ov − 1.222)` 对 ov
**是凸函数**，所以

> 保持逐网线 overflow 的均值 **不等于** 保持 γ 的均值：
> 由 Jensen 不等式 `E[coef(ov)] > coef(E[ov])`。

直接测量（adaptec1，新增的 `gamma_local:` 诊断日志）：

| 迭代（每 100） | mean(coef_net)/coef |
|---|---|
| 早期 | 0.87 → 0.75 |
| 中期 | 1.39 → 2.14 → 3.18 → 3.90 → **5.05** → 4.23 |

**所谓「局部化」实际上把线长模型平均平滑了最多 5 倍**（大 γ = 弱线长力，
见 §2）。这完全解释了三件事：overflow 被推高、wHPWL 大幅变差、以及镜像
为何无效（镜像保方差 ⇒ 保 Jensen 膨胀）。

**§3.2 第 3 步的保均值归一化解决了一半问题，但解错了空间**：它保住了
overflow 的均值，而真正需要保住的是 **γ 的均值**。第一阶段测的是
「局部化 + 平均平滑 5 倍」的混合体，不是局部化本身。

## 7. 第二阶段（Jensen 修正）——预注册

新增 `gamma_local_norm`：

- `"overflow"`（第一阶段，默认）：保 overflow 均值；
- `"gamma"`（第二阶段）：额外把 `coef_net` 整体除以 `mean(coef_net)/coef`，
  使**逐网线 γ 的均值精确等于全局调度值**。此时局部化成为 γ 自身的纯粹
  空间再分配，与「模型整体变平滑」彻底解耦。

臂：`npos`（sign=+1）、`nneg`（sign=−1），各 8 设计，其余参数不变。
**符号判据在此重做**：第一阶段的符号效应被 5× 的平滑淹没了，只有在
Jensen 修正之后它才是受控的。

### 预注册预测（写于第二阶段任何运行之前）

**H1（混杂被消除）**：两臂的 `mean(coef_net)/coef` 诊断值恒为 1.000，
且 ov@100 的平均偏移 **< +0.04**（第一阶段是 +0.095/+0.108）。
若 ov@100 的偏移基本消失 ⇒ §6.4 的诊断成立，第一阶段的 overflow 位移
**几乎全部来自平均平滑而非局部化**。

**H2（符号在受控条件下是否重新出现）**：npos 与 nneg 的 ov@100 平均偏移
**符号相反**，且 |差值| > 0.02。
- 成立 ⇒ 空间指派方向确实有作用，只是此前被淹没；
- 不成立 ⇒ γ 的空间再分配对 overflow 轨迹**没有一阶作用**，N4 作为
  overflow 杠杆被证伪，`OVERFLOW_ANALYSIS` §7A 与 `MECHANISM_ANALYSIS` N4
  都应据此撤回。

**H3（质量 —— 主判据）**：两臂的去混杂残差都 **< +1.0pp**（第一阶段是
+3.31/+5.48），即修正后不再有灾难性劣化。
**开放问题**：是否有一臂 < −0.5pp。不预测方向。

**H4（bigblue3）**：bigblue3 的残差从第一阶段的 +16.11/+25.45 降到
**< +3pp**。它是拥塞最不均匀的设计，因此也是 Jensen 膨胀最严重的受害者；
若修正后它仍然爆炸，说明还有第二个未识别的混杂。
