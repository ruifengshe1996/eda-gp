# 实验 2：障碍感知连通性场 —— 让场绕开宏

## 背景

连通性场初始化（实验 0b）对网表做阻尼 Jacobi 松弛得到有序嵌入，再吸附
到可行格点。但场的**松弛过程本身对固定宏视而不见**：调和场穿透障碍物，
一个单元可能被平滑到某块大宏的"错误一侧"，吸附步只能把它弹到宏边缘，
不能纠正侧别。ISPD2005 中 adaptec2、adaptec4 宏多且大，恰是场初始化
表现最差的设计。

## 动机

两个假设：

- **H1（障碍错侧）**：adaptec2 / adaptec4 的退化来自单元被嵌到宏的
  错误一侧——若在场演化中就阻止穿透，应能修复；
- **H2（坍缩的障碍成因）**：bigblue3 型的场整体坍缩（实验 1 的灾难源头）
  可能也与障碍处理有关，障碍感知的场或许能在源头缓解。

## 方法

对固定单元占用做半步栅格化，用一次欧氏距离变换（EDT）预计算每个被占
栅格点的最近自由点；**每次 Jacobi 扫掠结束后**，把落入障碍内部的单元
中心投影到最近自由点。场的松弛始终在可行域附近演化，单元在扫掠间被迫
选择正确的一侧绕行。两个变体：

- **obsfield** = 障碍投影场 + 格点吸附；
- **obsspread** = 障碍投影场 + 容量展开（实验 1）+ 吸附。

## 实现

`ConnectivityGridInit.py` 的 `_make_obstacle_projector`（scipy EDT，
`return_indices` 一次算好映射，逐扫掠 O(单元数) 应用）；开关
`conn_obstacle_project_flag`（默认关），与展开开关正交可组合。

## 结果

**数据有效性**：本实验 GPU 运行受 conn-y 缺陷影响（实测为意外变体，
y 是底行直线）。意外变体成绩曾显示 obsfield 把 adaptec2 从 +2.04% 修到
+0.49%、几何平均 +0.79%，当时被解读为 H1 的有力证据——事后看该修复
效应大部分是缺陷伪影。

**修复后重跑**（实验 R，权威数字）：

| 变体 | 几何平均 | 迭代 | adaptec2 | bigblue3 |
|---|---|---|---|---|
| 连通性场（对照） | +0.40% | −5~15% | +0.58% | +0.86% |
| obsfield | **+0.34%** | −4~16% | +0.37% | +0.75% |
| obsspread | +1.82% | **−18~34%** | +1.14% | +9.27% |

obsfield 相对纯场初始化的增益缩小为温和的整体改善（adaptec2
+0.58→+0.37，bigblue3 +0.86→+0.75），adaptec1 与 bigblue4 微胜中心
初始化（−0.03% / −0.07%）。

## 反思

- **H1 弱成立**：障碍投影计算便宜、方向正确、处处无害，但"错侧"只解释
  adaptec2 一小部分退化，而非当年以为的大部分——一个方法论教训是，
  意外变体曾把噪声性的修复放大成"机制证据"。
- **H2 不成立**：bigblue3 的场坍缩是连通结构本身驱动的（该网表高度
  聚簇），与障碍无关；障碍感知场救不了展开灾难，正解最终由实验 6 的
  保序收缩给出（bigblue3 −0.10%）。
- obsfield 是目前**速度-质量折中点**：以 −4~16% 迭代拿到 +0.34%，
  适合作为展开系（更快但更损质量）与收缩系（质量最优但不省迭代）之间
  的中间档。
